## Retail & Warehouse Sales Analysis Using Python

Project Overview-

This project focuses on Exploratory Data Analysis (EDA) of a retail and warehouse sales dataset containing approximately 30,000 records. The analysis was performed using Python to understand recorded sales and transfer patterns, explore product-level performance, and identify data quality issues.

Tools & Technologies

Python

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook

Project Objectives-

Perform data cleaning and initial data quality checks.

Explore sales and transfer records across the available reporting months.

Analyse performance across different item types, suppliers, and products.

Examine descriptive statistics and correlations among recorded variables.

Visualise patterns and trends using charts and graphs.

Identify missing values, negative records, and limitations in the dataset.

Key Activities

Imported and explored the dataset using Pandas and NumPy.

Checked for missing values and potential data quality issues.

Conducted exploratory analysis of sales and transfer records.

Compared results across item types, suppliers, and products.

Used Matplotlib and Seaborn to create visualisations.

Interpreted findings while considering the limitations of the available data.

Key Observations

The dataset contains missing values and negative records that require careful interpretation.

Monthly reporting coverage is uneven across the available 2020 period.

Sales and transfer patterns vary across item types, suppliers, and products.

Data quality and reporting limitations should be considered before using the findings for operational decisions.

Project Outcome

The project demonstrates practical application of Python for data cleaning, exploratory data analysis, descriptive statistics, and data visualisation. It also highlights the importance of validating data quality before drawing business conclusions.

Note

This is a descriptive exploratory analysis project. The findings should not be interpreted as predictive results.
